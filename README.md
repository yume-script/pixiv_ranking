# Pixiv 랭킹 (pixiv_ranking)

BookOasis에 픽시브(Pixiv) 랭킹을 보여주는 메타데이터 플러그인입니다.
검색/적용(search/apply) 기능은 없고, 두 가지 화면을 동시에 지원합니다.

- **카테고리 풀페이지 탭** (`category_tab`, 기존 기능 그대로): 좌측 카테고리 메뉴에서
  전체 랭킹을 그리드로 조회
- **홈 대시보드 위젯** (`home_widget`, 신규): 사용자 홈 화면에 후보 풀 중 **무작위로
  고른 이미지 1장**만 카드로 노출 (여러 장의 그리드가 아님)

두 화면 모두 같은 백엔드 로직(`get_dashboard_data`)을 재사용하며, 호출 시 `limit` 값으로
"그리드 전체를 보여줄지"(카테고리 탭) / "무작위 1장만 보여줄지"(홈 위젯)를 구분합니다.

## 주요 기능

- 픽시브 랭킹(일간/주간/월간/신인/오리지널/AI생성/남자에게 인기/여자에게 인기)을
  콘텐츠 타입(종합/일러스트/우고이라/만화)별로 조회
- **어느 카테고리(세션)에서나 동작**: `sessions: "all"`로 선언되어 일반 도서/성인
  서재/오디오북/영상 강좌 4개 세션 어디에서나 카테고리 탭과 홈 위젯이 노출됩니다.
  픽시브 데이터는 코어 도서 라이브러리와 무관한 외부 콘텐츠이기 때문입니다.
- **카테고리 풀페이지 탭**: 좌측 카테고리 메뉴에서 전체 랭킹을 그리드로 표시, 화면 상단
  드롭다운으로 콘텐츠 타입/랭킹 모드/설정 적용 대상(스코프)을 즉시 변경 가능
- **홈 위젯**: 사용자가 "내 설정 > 홈 화면 플러그인 배치 모드"를 켜고 "+ 위젯 추가"로
  직접 추가했을 때만, 후보 풀 중 무작위로 고른 이미지 **1장**을 카드로 노출. 헤더/부제
  없이 순수하게 이미지 하나만 슬롯 크기에 꽉 차게 채우고, 우상단의 작은 새로고침
  버튼으로 다른 이미지를 다시 뽑을 수 있음 (스크롤바가 생기지 않도록 항상 주어진
  위젯 크기에 맞춰짐)
- SJVA 회원인증(API Key + 홈페이지 ID)이 되어 있지 않으면 두 화면 모두 비활성화됨
- 썸네일 이미지는 로컬에 저장하지 않고, 요청 시점에 서버가 픽시브에서 직접 받아
  base64 데이터 URI로 변환해 응답에 실어 보냄 (브라우저 직접 요청 시 발생하는
  Referer 누락 403 문제를 서버 사이드 프록시로 우회)
- 각 단계(설정 로드 → 랭킹 조회 → 썸네일 수집 → 완료)마다 서버 로그와 브라우저
  콘솔에 진행 상황을 남김

## 설치

1. 이 폴더 전체를 서버의 `plugins/metadata/pixiv_ranking/`에 그대로 복사합니다.
2. 서버를 재시작합니다.
3. 환경설정 > 플러그인 설정에서 **Pixiv 랭킹**을 활성화합니다.
4. 아래 설정값을 입력하고 저장합니다.
5. **카테고리 탭 확인**: 좌측 카테고리 메뉴에서 카드 그리드가 보이는지 확인합니다
   (일반/성인/오디오북/비디오 4개 세션 어디에서나 노출됩니다).
6. **홈 위젯 확인**: 내 설정 > 홈 화면 플러그인 배치 모드를 켠 뒤, 홈 화면 하단
   "+ 위젯 추가" 목록에서 **Pixiv 랭킹**을 직접 추가합니다. (설치/활성화만으로는
   자동 노출되지 않으며, 사용자가 직접 골라야 홈 화면에 들어갑니다. 이 역시
   4개 세션 어디에서나 추가할 수 있습니다.)
7. **설정 적용 대상(스코프) 확인**: 카테고리 탭 화면 상단의 "설정 적용 대상"
   드롭다운을, 실제로 6번에서 설정값을 저장한 스코프(보통 "일반")와 동일하게
   맞춰주세요. 아래 "여러 세션 지원 방식" 항목 참고.

## 설정값

| 키 | 설명 | 필수 |
| :--- | :--- | :--- |
| `SJVA_APIKEY` | SJVA 회원인증 API Key (sjva.me 홈페이지에 등록된 apikey) | 필수 |
| `SJVA_USER_ID` | SJVA 홈페이지 로그인 ID | 필수 |
| `PHPSESSID` | 픽시브 로그인 세션 쿠키. 로그인 상태의 브라우저 개발자도구 > Application/저장공간 > 쿠키에서 확인 | 필수 |
| `MODE` | 랭킹 모드 기본값 (daily/weekly/monthly/rookie/original/daily_ai/male/female) | 기본값 daily |
| `CONTENT` | 콘텐츠 타입 기본값 (all/illust/ugoira/manga) | 기본값 all |
| `LIMIT` | 후보 풀 크기 — 카테고리 탭 그리드 개수이자, 홈 위젯이 무작위로 고를 대상 풀 크기 (10/20/30/50) | 기본값 50 |
| `THUMB_SIZE` | 썸네일 크기 (128x128/240x480/360x360_70/480x960) | 기본값 240x480 |

`MODE`/`CONTENT`는 카테고리 탭 화면 상단 드롭다운으로 요청 시점에 덮어쓸 수 있습니다
(드롭다운을 조작하지 않으면 위 설정값이 그대로 사용됩니다). 홈 위젯은 항상 설정값의
`MODE`/`CONTENT`/`LIMIT` 기준으로 후보 풀을 만든 뒤 그중 1개를 무작위로 뽑습니다.

## 파일 구성

```text
pixiv_ranking/
  __init__.py       # 플러그인 클래스 export
  pixiv_ranking.py  # 플러그인 본체 (search/apply, category_tab, home_widget, get_dashboard_data)
  VERSION           # 자동 업데이트용 버전 파일 ("plugin version" 키)
  index.html        # 카테고리 풀페이지 뷰 마크업
  style.css         # 카테고리 풀페이지 뷰 스타일
  script.js         # 카테고리 풀페이지 뷰 동작 (데이터 요청, 렌더링, 드롭다운 처리)
  dashboard.html    # 홈 위젯 마크업 - 헤더/부제 없이 이미지 카드 하나만 (Shadow DOM 안에 주입됨)
  dashboard.css     # 홈 위젯 전용 스타일 - 슬롯 크기(100%)에 맞춰 채워 스크롤바 방지
  dashboard.js      # 홈 위젯 동작 - function(pluginId, shadowRoot, items) 형태로 실행
  settings.html     # 환경설정 커스텀 폼 (평소엔 접혀 있다가 클릭 시에만 펼쳐짐)
  settings.css      # 환경설정 커스텀 폼 스타일
  requirements.txt  # 외부 의존성 없음 (표준 라이브러리만 사용)
```

`settings.html`이 있으면 `config_schema` 기반 코어 자동 생성 폼 대신 이 커스텀 폼이 사용됩니다.
값 저장은 `input`/`select`의 `name` 속성이 설정 키(`SJVA_APIKEY`/`PHPSESSID`/`MODE`/`CONTENT`/...)와
일치하면 코어가 자동으로 처리합니다.

## 동작 방식 요약

1. `get_dashboard_data(db_type, limit)` 호출 시, SJVA 회원인증을 먼저 확인하고
   설정값(`PHPSESSID`/`MODE`/`CONTENT`/`LIMIT`/`THUMB_SIZE`)을 불러옵니다.
2. **`limit == 1`로 호출되면 "홈 위젯 랜덤 1장 모드"** 로 간주합니다
   (`home_widget.limit`을 1로 선언해뒀기 때문에 코어가 홈 위젯을 그릴 때 이 값으로 호출함).
   이때는 설정된 `LIMIT`(예: 50)만큼 후보 풀을 받아온 뒤 `random.choice()`로 1개만 고릅니다.
   그 외의 `limit`(카테고리 탭이 명시적으로 `limit=50`을 요청)은 기존처럼 전체 그리드를 반환합니다.
3. 카테고리 탭에서 드롭다운으로 `mode`/`content` 쿼리 파라미터가 함께 전달되면
   (`/api/media/dashboard/widgets/pixiv_ranking/data?...&mode=...&content=...`)
   설정값보다 그 값을 우선 사용합니다.
4. 픽시브 랭킹 JSON(`ranking.php?...&format=json`)을 조회합니다.
5. 선택된 항목(전체 또는 무작위 1개)의 썸네일을 최대 5개씩 동시에(`ThreadPoolExecutor`)
   받아 base64 데이터 URI로 변환합니다.
6. 코어 카드 렌더러가 읽는 `cover/title/author/publisher/link` 필드(및 `image`/`url` 등 별칭)로
   묶어 반환합니다.

## 여러 세션(일반/성인/오디오북/비디오) 지원 방식

`category_tab`/`home_widget` 모두 `sessions: "all"`로 선언해 4개 세션 어디에서나 탭/위젯
자체는 노출됩니다. 다만 실제 동작에는 한 가지 전제가 있습니다:

- `get_plugin_config(db_type, ...)`는 `db_type`별로 **별도 저장된 설정값**을 읽습니다
  (일반 스코프에 저장한 `PHPSESSID`는 성인/오디오북/비디오 스코프에서는 보이지
  않을 수 있습니다). 즉 관리자가 환경설정에서 PHPSESSID 등을 저장한 스코프
  **하나**에서만 정상적으로 데이터가 나옵니다(보통 "일반").
- 코어가 "지금 사용자가 어느 세션을 보고 있는지"를 플러그인 프론트엔드(JS)에
  공식적으로 알려주는 방법을 문서에서 찾지 못했습니다. 그래서 이 플러그인은
  카테고리 탭 화면 상단에 **"설정 적용 대상"** 드롭다운을 두어, 사용자가
  실제로 설정값을 저장해 둔 스코프를 직접 고르도록 했습니다. 고른 값은
  `localStorage`(`pixiv_ranking:config_scope`)에 저장되어 브라우저 단위로
  기억되며, 홈 위젯의 새로고침 버튼도 같은 값을 공유해서 사용합니다.
- 정리하면: **어느 세션의 사이드바/홈 화면에서 열든 탭과 위젯은 보이지만,
  실제로 픽시브 데이터를 정상적으로 가져오려면 "설정 적용 대상"을 관리자가
  설정값을 저장해 둔 스코프와 일치시켜야 합니다.** 처음 설치 후 헷갈린다면
  일단 "일반"으로 두고, 환경설정에서 저장한 스코프도 "일반"으로 맞추는 것을
  권장합니다.

## 알려진 제약 / 확인이 필요한 부분

- **드롭다운 → 백엔드 값 전달 방식이 비공식입니다.** `get_dashboard_data(self, db_type, limit=10)`
  시그니처에 `mode`/`content`를 받을 자리가 없어서, `flask.request.args`로 현재 요청의 쿼리
  파라미터를 직접 읽는 방식으로 우회했습니다. 코어가 실제로 이 값을 그대로 통과시켜주는지는
  서버 로그의 `0/3 설정 로드 완료` 줄에서 `mode=`/`content=` 값이 드롭다운 선택과 일치하는지
  확인해야 합니다.
- **"홈 위젯 = limit==1" 판별도 같은 성격의 관찰 기반 우회입니다.** 코어가 `home_widget`을
  그릴 때 실제로 `home_widget.limit`(=1)을 그대로 `get_dashboard_data(limit=...)`에 넘겨주는지
  가정하고 구현했습니다. 만약 코어가 다른 값으로 호출한다면 서버 로그의
  `0/3 설정 로드 완료` 줄에서 `요청 limit=`/`랜덤 1장 모드=` 값을 확인해 판별 조건을
  조정해야 합니다.
- **소설(novel) 랭킹은 지원하지 않습니다.** URL 구조와 JSON 스키마가 달라 별도 검증이
  필요해서 제외했습니다.
- **원본(고해상도) 이미지 URL은 참고용 추정치**(`original_url_guess`)로만 제공됩니다.
  원본이 PNG인 작품은 이 변환만으로는 404가 날 수 있습니다.
- **환경설정 화면 레이아웃**은 `settings.html`/`settings.css` 커스텀 폼으로 라벨-입력을 좌우로
  배치했고, 평소엔 `<details>`로 접혀 있다가 클릭 시에만 펼쳐집니다.
- `update_manifest.enabled`는 `True`로 되어 있고 `raw_base_url`이 실제 저장소
  (`https://github.com/yume-script/pixiv_ranking`)를 가리킵니다. 이 폴더 내용을 그대로
  그 저장소에 반영해야 자동 업데이트 버튼이 정상 동작합니다(신규 파일인
  `dashboard.html`/`dashboard.css`/`dashboard.js`도 `files` 목록에 추가해뒀습니다).

## 문제 해결

- **카테고리 탭 카드에 이미지가 안 뜸**: 서버 로그의 `2/3 썸네일 수신 실패` 줄에서
  사유(타임아웃/네트워크 오류)를 확인하세요. `PHPSESSID`가 만료됐을 가능성이 가장 큽니다.
- **홈 위젯이 안 보임**: "홈 화면 플러그인 배치 모드"가 켜져 있는지, 홈 화면 "+ 위젯 추가"
  목록에서 실제로 추가했는지 먼저 확인하세요. 설치/활성화만으로는 노출되지 않습니다.
- **랭킹 자체가 안 뜸**: `1/3 랭킹 응답 수신` 로그의 `status`와 응답 앞부분을 확인하세요.
  로그인 세션이 없거나 만료되면 HTML(로그인 페이지)이 내려와 JSON 파싱에 실패합니다.
- **SJVA 인증 실패**: 서버 로그의 `SJVA 인증 실패` 줄에서 `result` 값(`wrong_id`/`wrong_apikey`)을
  확인하세요.
- **브라우저 콘솔**: 카테고리 탭은 `[Pixiv-Ranking-Plugin]`, 홈 위젯은
  `[pixiv_ranking][home_widget]` 접두사 로그로 요청 URL, 응답 상태, 이미지 로드 실패 여부까지
  확인할 수 있습니다.
